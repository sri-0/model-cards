# Qwen3 Embedding 4B

## Overview
Qwen3-Embedding-4B was released on 2025-06-05 alongside the 0.6B and 8B models (Hugging Face repo created 2025-06-03; technical report arXiv 2506.05176). OpenRouter serves it on its embeddings endpoint as `qwen/qwen3-embedding-4b` with a 32,768-token context. It fine-tunes Qwen3-4B-Base (36 layers, 4.0B parameters) through contrastive pre-training on weakly supervised pairs generated by Qwen3, supervised training and model merging, and takes the final [EOS] token's hidden state as the embedding. Output is 2,560 dimensions, and any size from 32 to 2,560 can be requested. Qwen states a 32K sequence length; config.json allows 40,960 positions. Queries take a one-sentence instruction (`Instruct: {task}\nQuery:{query}`); documents take none. Qwen publishes GGUF files, and Ollama serves it as `qwen3-embedding:4b`.

## Strengths
- Qwen reports MTEB (Multilingual) Mean (Task) 69.45, MTEB (English, v2) 74.60 and C-MTEB 72.27, with the best Instruction Retrieval score (11.56) in its table. The MTEB leaderboard showed 69.45 and 74.60 on 2026-11-01.
- Within about one point of the 8B model (70.58) at roughly half the parameters.
- 100+ languages, including programming languages, for cross-lingual and code retrieval.
- Apache 2.0; Sentence Transformers, Transformers, vLLM and Text Embeddings Inference usage is documented.

## Limitations
- Far heavier than the 0.6B model, which scores 64.33 multilingual.
- Omitting the query instruction costs about 1% to 5% in retrieval, per Qwen; instructions should be in English.
- Pooling takes the last token, so batched inference needs left padding or the card's `last_token_pool` code.

## Good for
- Multilingual RAG where the 8B model is too large.
- Code search and cross-lingual retrieval.
- Teams already serving Qwen models with vLLM.
