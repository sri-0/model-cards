# Qwen-Plus-Character-JA

## Overview
Qwen-Plus-Character-JA (Model Studio id `qwen-plus-character-ja`) is a Japanese role-playing model released on 2025-07-21; no weights are published and OpenRouter does not list it, so the id is the DashScope model id. Model Studio says the Qwen role-playing series is optimised here for Japanese anthropomorphic interaction, with character consistency, context-aware dialogue progression and empathetic engagement, and that this version improves Japanese localisation, including dialects and honorifics, human-like role-play, narrative coherence and scenario reasoning. It has an 8,192-token context with up to 4,096 output tokens and no function calling, structured output, web search or caching. The Singapore price is $0.50 input, $1.40 output and $0.10 for cached input per million tokens.

## Strengths
- Japanese honorifics and dialects in character.

## Limitations
- Short 8,192-token context.
- No structured output or tools.

## Good for
- Japanese companion and game-character chat.
