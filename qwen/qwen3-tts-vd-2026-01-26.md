# Qwen3-TTS-VD 2026-01-26

## Overview
Status: Model Studio's current pricing and speech synthesis pages no longer list this snapshot; archived pricing pages show it on 2026-10-07 but not on 2026-10-13, and the deprecation page names no date for it. `qwen3-tts-vd-2026-01-26` is the only id of the non-real-time Qwen3-TTS-VD model, a dated snapshot with no stable id; Model Studio's release table lists it from 2026-02-10. No weights are published and OpenRouter does not list it, so the id is the DashScope model id. Model Studio describes it as a Qwen3-TTS speech synthesis model that renders, with high fidelity, voices designed by the qwen3-voice-design service from a text description, keeping one voice across languages and adapting tone to the text. The release table says 11 languages; the pricing page lists Chinese (Mandarin), English, Spanish, Russian, Italian, French, Korean, Japanese, German and Portuguese. A request takes up to 600 characters. It was priced at $0.115 per 10,000 characters in Singapore, with each Chinese character counted as two.

## Strengths
- Brand or character voices without any recording.
- Same per-character price as the voice-clone snapshot.

## Limitations
- No longer listed for sale on Model Studio.
- Designed voices only; no system voices.
- 600 characters per request.

## Good for
- Interpreting older integrations that pinned this snapshot.
