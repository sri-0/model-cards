# Qwen-Math-Plus

## Overview
Status: Model Studio's current pricing page no longer lists qwen-math-plus; archived pricing pages show it on 2026-10-07 but not on 2026-10-13, and the deprecation page names no date for it. Qwen-Math-Plus (Model Studio id `qwen-math-plus`, documented as equivalent to `qwen-math-plus-2024-09-19`, also `qwen-math-plus-0919`, with an earlier `qwen-math-plus-2024-08-16` (0816) snapshot and a `-latest` alias) appears in Model Studio's release table on 2024-09-13; no weights are published and OpenRouter does not list it, so the id is the DashScope model id. Model Studio describes a powerful maths problem-solving model that excels at Chinese and English mathematical tasks, including equations, calculations and proofs. The archived models page gives a 4,096-token context with 3,072 input and 3,072 output tokens. It was priced for China (Beijing) at $0.574 input and $1.721 output per million tokens.

## Strengths
- Step-by-step maths in Chinese and English.

- Tiny 4,096-token context.
