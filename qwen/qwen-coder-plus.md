# Qwen-Coder-Plus

## Overview
Status: Model Studio's current pricing page no longer lists qwen-coder-plus; archived pricing pages show it on 2026-10-07 but not on 2026-10-13, and the deprecation page names no date for it. Qwen-Coder-Plus (Model Studio id `qwen-coder-plus`, documented as equivalent to `qwen-coder-plus-2024-11-06`, also `qwen-coder-plus-1106`, with a `-latest` alias) appears in Model Studio's release table on 2024-11-12; no weights are published and OpenRouter does not list it, so the id is the DashScope model id.
