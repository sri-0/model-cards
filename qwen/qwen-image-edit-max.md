# Qwen-Image-Edit-Max

## Overview
Status: Model Studio's current pricing and image-generation pages no longer list qwen-image-edit-max; archived pricing pages show it on 2026-10-07 but not on 2026-10-13, and the deprecation page names no date for it. Qwen-Image-Edit-Max (Model Studio id `qwen-image-edit-max`, documented as currently equivalent to `qwen-image-edit-max-2026-01-16`) appears in Model Studio's release table on 2026-01-15; no weights are published and OpenRouter does not list it, so the id is the DashScope model id. Model Studio describes the Max editing series as more stable and versatile: stronger industrial design and geometric reasoning, better character consistency, reduced offset (drift) problems, and integrated LoRA capabilities for a wider range of edits. It was priced at $0.075 per output image in Singapore and $0.071677 in China (Beijing), against $0.03 for Qwen-Image-Edit-Plus.

## Strengths
- Artificial Analysis image-editing Elo 982 (as Qwen Image Edit Max 2601), above Qwen-Image-Edit-2509 (965).
- Consistent people and products across edits, per Model Studio.

## Limitations
- No longer listed for sale on Model Studio.
- Below the open Qwen-Image-Edit-2511 (991) and far below Qwen-Image-2.0-Pro (1058) on AA's editing arena.
- Two and a half times the price of Qwen-Image-Edit-Plus.
