# Qwen3-TTS-VC 2026-01-22

## Overview
Status: Model Studio's current pricing and speech synthesis pages no longer list this snapshot; archived pricing pages show it on 2026-10-07 but not on 2026-10-13, and the deprecation page names no date for it. `qwen3-tts-vc-2026-01-22` is the only id of the non-real-time Qwen3-TTS-VC model, a dated snapshot with no stable id; Model Studio's release table lists it from 2026-02-10. No weights are published and OpenRouter does not list it, so the id is the DashScope model id. Model Studio describes it as a Qwen3-TTS-Flash speech synthesis model that renders, with high fidelity, voices replicated by the qwen-voice-enrollment service, keeping the same timbre across languages and adapting tone to the text. The release table says 11 languages; the pricing page lists Chinese (Mandarin), English, Spanish, Russian, Italian, French, Korean, Japanese, German and Portuguese. A request takes up to 600 characters. It was priced at $0.115 per 10,000 characters in Singapore, with each Chinese character counted as two; creating a cloned voice through qwen-voice-enrollment cost $0.01 per voice.

## Strengths
- Reuses one cloned voice across ten languages.
- Low per-character price.

## Limitations
- No longer listed for sale on Model Studio.
- Cloned voices only; no system voices.
- 600 characters per request.

## Good for
- Interpreting older integrations that pinned this snapshot.
