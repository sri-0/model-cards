# o1

## Overview
o1 is the model OpenAI's page now calls its previous full o-series reasoning model, released on 2024-12-05 (Artificial Analysis date; pinned snapshot `o1-2024-12-17`). OpenRouter does not list it, so the id is OpenAI's API id under the vendor prefix and the frontmatter carries no OpenRouter price or parameters; the limits come from OpenAI's page. OpenAI says the o1 series is trained with reinforcement learning to produce a long internal chain of thought before answering. It takes text and images and returns text, with a 200,000-token context window, 100,000 max output tokens and an October 2023 knowledge cutoff. OpenAI served it on Chat Completions, Responses and Batch, with streaming, function calling, structured outputs, image input and reasoning tokens; no fine-tuning. OpenAI's price was $15 input, $7.50 cached input and $60 output per million tokens ($7.50 and $30 in batch). OpenAI lists it as Shut down: announced 2026-04-22, it left the API on 2026-10-23 with `gpt-5.6-sol` as the recommended replacement; Artificial Analysis names o3 as its successor. The earlier `o1-preview` was shut down on 2025-07-28 in favour of o3.

## Strengths
- Artificial Analysis measured 74.7% on GPQA Diamond, 70.3% on IFBench, 65.0% on AA-LCR and 62.6% on tau2-bench.
- Structured outputs and function calling, which o1-mini lacked.
- Image input within a 200K-token window.

## Limitations
- Shut down on OpenAI's API and not listed on OpenRouter.
- $60 per million output tokens, and OpenAI bills hidden reasoning tokens as output.
- 7.0% on Humanity's Last Exam and 12.9% on Terminal-Bench Hard.
- Artificial Analysis publishes no current speed figures for it.

## Good for
- Reproducing results from systems built on the first o-series generation.
- Comparisons against OpenAI's December 2024 reasoning baseline.
