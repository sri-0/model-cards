# o3

## Overview
o3 is OpenAI's full-size reasoning model of April 2025, released on 2025-04-16 (Artificial Analysis date; pinned snapshot `o3-2025-04-16`). OpenAI and OpenRouter describe it as a well-rounded model across maths, science, coding and visual reasoning that also does well at technical writing and instruction following; OpenRouter marks reasoning as mandatory. It takes text and images and returns text, with a 200,000-token context window, 100,000 max output tokens and a June 2024 knowledge cutoff. OpenAI serves it on Chat Completions, Responses and Batch, with streaming, function calling, structured outputs, image input and prompt caching; no fine-tuning. OpenAI's Batch and Flex prices are $1 input and $4 output per million tokens, half the standard rate, and the OpenRouter batch endpoint `openai/o3:batch` charges the same. OpenAI marks it Deprecated and says it is succeeded by GPT-5: announced 2026-06-11, it leaves the API on 2026-12-11 with `gpt-5.6-sol` as the recommended replacement. Artificial Analysis had not marked it deprecated on 2026-11-01.

## Strengths
- Artificial Analysis measured 82.7% on GPQA Diamond, 80.7% on tau2-bench, 74.7% on AA-LCR, 71.4% on IFBench and 70.1% on MMMU-Pro.
- 37.1% on Terminal-Bench Hard and 20.1% on Humanity's Last Exam.
- About 147 output tokens per second with a 5.81-second time to first token, which includes reasoning.
- $2 input and $8 output per million tokens, with cache reads at $0.50.

## Limitations
- Deprecated, with removal from OpenAI's API on 2026-12-11.
- Reasoning cannot be switched off, and OpenAI bills hidden reasoning tokens as output.
- No fine-tuning.
- Knowledge stops at June 2024.

## Good for
- Maths, science and coding questions that need multi-step reasoning.
- Agentic tool use and long-document analysis until the December 2026 shutdown.
