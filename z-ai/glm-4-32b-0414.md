# GLM-4-32B-0414

## Overview
GLM-4-32B-0414 was released on 2025-04-14 with the GLM-Z1 reasoning models that were trained from it. It is a dense 32B model pre-trained on 15T tokens, including substantial synthetic reasoning data, then aligned with rejection sampling and reinforcement learning for instruction following, engineering code and function calling. The open weights have a 32,768-token window (config.json); Z.ai's API serves it as `glm-4-32b-0414-128k` with a 128K context, 16K maximum output and a flat $0.1 per million input and output tokens, plus optional web search at $0.01 per use. OpenRouter does not currently list it; the id follows the Hugging Face repo `zai-org/GLM-4-32B-0414`. Weights are MIT-licensed.

## Strengths
- Z.ai reports 87.6 on IFEval, 69.6 on BFCL-v3 overall, and 68.7 and 51.2 on TAU-Bench retail and airline, matching or beating GPT-4o-1120 and DeepSeek-V3-0324 on each in its table.
- Search-augmented answering: 88.1 on SimpleQA and 63.8 on HotpotQA with search and click tools, per Z.ai.
- Very cheap on Z.ai's API, and Z.ai describes it as easy to deploy locally.

## Limitations
- No thinking mode; GLM-Z1-32B-0414 is the reasoning variant.
- Z.ai reports 33.8% at best on SWE-bench Verified (Moatless), far below later GLM models.
- 32K native context for local deployment.
- Artificial Analysis does not test it.

## Good for
- Low-cost tool calling, information extraction and search-grounded Q&A.
- Self-hosted Chinese and English chat on modest hardware.
