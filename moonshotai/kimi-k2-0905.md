# Kimi K2 0905

## Overview
Kimi K2 Instruct 0905 updates Kimi K2 0711 with the same architecture: a mixture-of-experts model with 1T total and 32B activated parameters (384 experts, 8 per token). Moonshot's Hugging Face card lists better agentic coding, better front-end code and a context window raised from 128K to 256K tokens. It is a text-only, non-thinking model. Weights are on Hugging Face as `moonshotai/Kimi-K2-Instruct-0905` in block-FP8 under a Modified MIT licence, with vLLM, SGLang, KTransformers and TensorRT-LLM recommended for serving. Moonshot's API id `kimi-k2-0905-preview` was discontinued on 2026-05-25, and Artificial Analysis marks the model deprecated in favour of Kimi K2.5. OpenRouter still routes it to Novita.

## Strengths
- Moonshot reports 69.2% on SWE-bench Verified (up from 65.8% for 0711), 55.9% on SWE-bench Multilingual and 44.5% on Terminal-Bench, each a mean of five runs.
- Artificial Analysis measured 73.4% on tau2-bench and 23.5% on Terminal-Bench Hard, both higher than 0711.
- Fast first token (1.34 s per Artificial Analysis) and structured output on OpenRouter.

## Limitations
- No thinking mode: 6.4% on Humanity's Last Exam and 53% on AA-LCR per Artificial Analysis.
- Gone from Moonshot's API; later Kimi models add reasoning and vision.
- The 1T-parameter weights need a multi-GPU cluster to self-host.

## Good for
- Coding agents that need a 256K window and fast, non-reasoning replies.
- Self-hosted deployments standardised on the Kimi K2 architecture.
